# TechnoMagicRPG — обновления

Здесь лежат файлы сборки для онлайн-обновления лаунчера.

## Что это

- `manifest.json` — список файлов с контрольными суммами;
- `mods/`, `config/`, `shaderpacks/` — сами файлы;
- `options.txt`, `servers.dat` — настройки и список серверов.

Лаунчер скачивает `manifest.json`, сравнивает суммы со своими файлами
и докачивает только изменившееся.

## Как выпустить обновление

1. обновить файлы в этой папке;
2. пересобрать манифест;
3. отправить изменения на GitHub:
   ```
   cd packaging/update/repo
   git add -A
   git commit -m "обновление сборки"
   git push
   ```
4. сменить версию в манифесте — лаунчер увидит новую и предложит обновиться.
